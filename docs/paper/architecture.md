## Figure 2: Multi-Agent Pipeline Flow

```

                    │
                    ▼
        ┌───────────────────────┐
        │    PLANNER AGENT      │
        │  Intent: CLINICAL     │
        │  Needs RAG: Yes       │
        │  Needs Meals: Yes     │
        │  Collection: nutrisync│
        └───────────┬───────────┘
                    │
            ┌───────┴───────┐
            ▼               ▼
    ┌───────────────┐ ┌───────────────┐
    │ ANALYZER:     │ │ ANALYZER:     │
    │ Retrieve      │ │ Analyze       │
    │ Knowledge     │ │ Meal History  │
    │ (Parallel)    │ │ (Parallel)    │
    └───────┬───────┘ └───────┬───────┘
            │                 │
            └────────┬────────┘
                     ▼
        ┌───────────────────────┐
        │     COACH AGENT       │
        │  Query Decomposition: │
        │  1. Diabetes nutrition│
        │  2. South Indian foods│
        │  3. Low-GI options    │
        │                       │
        │  Response + Citations │
        └───────────┬───────────┘
                    │
                    ▼
        ┌───────────────────────┐

                    │

        └───────────────────────┘
```
